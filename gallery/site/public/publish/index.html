Cloudflare 连接 未连接

勾选记住后，令牌只加密保存在此设备；只有持有令牌才能上传、修改或删除内容。令牌不会发送给 GitHub 或其他服务。

令牌从哪里来？

发布令牌是你在 Cloudflare 上传服务（Worker）的 AUTH_TOKEN 中设置的密钥。连接时会先做一次不改变任何内容的写入检查，确认令牌和存储都可用。

存储设置

照片原图与专辑配置存储在 Cloudflare R2；提交后自动触发 Pages 重建，访客从 Cloudflare 加载全部图片。发布页通过同源 /api 访问上传服务，不经过 GitHub。

本机草稿与隐私

点击「保存本机草稿」才会将照片和文案存入设备浏览器。草稿不包含令牌；只生成配置也不会上传照片。点击发布并确认后才会上传到 Cloudflare R2 存储。

iPhone 可在 Safari 中添加到主屏幕。上传时请将页面保持在前台；不支持后台上传。Safari 私密浏览或系统清理可能使草稿丢失，请保留原图。
