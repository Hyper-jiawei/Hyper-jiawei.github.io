通用令牌怎么设置？

推荐 Fine-grained token：Resource owner 选你的账号或目标组织，Repository access 选 All repositories（覆盖当前及未来仓库）；Repository permissions 添加 Contents → Read and write、Repository creation → Read and write，Metadata 保留 Read-only。若界面暂未提供 Repository creation，Administration 写入也可建仓，但权限更大。

如果只上传几个已有仓库，可以保留 Only select repositories，把网站仓库和所有原图库都加进去；新建分仓后可能还需重新授权。

个人公开仓库也支持 Classic token 的 public_repo 范围。它会覆盖账号可访问的公开仓库，权限范围较广。组织还可能要求审批或 SSO。工具不会替你扩大令牌权限。

“账号已连接”只确认身份；“检查目标写入权限”会创建一个不关联提交的空 Git 对象来确认写入能力，不改变文件或触发部署。自动建仓权限只有实际需要创建时才能完整确认。

本机草稿与隐私

照片和文案只有点击「保存本机草稿」才保存在此设备的浏览器数据库，草稿不包含访问令牌，保存的连接单独存放，可在上方「断开并忘记此设备」中清除。只生成配置不会上传照片；只有点击底部发布按钮才上传到公开 GitHub 仓库。

Safari 私密浏览或系统清理可能使草稿丢失，请保留原文件。当前版本不支持后台上传。
