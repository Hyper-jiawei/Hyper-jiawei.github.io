通用令牌怎么设置？

推荐 Fine-grained token。Resource owner 选你的账号或目标组织。如果只用已有仓库，选 Only select repositories，并添加网站仓库和原图库。Repository permissions 添加 Contents → Read and write，Metadata 保留 Read-only。

如需自动创建未来的原图库，令牌范围需覆盖新仓库，并允许 Repository creation → Read and write。GitHub 组织可能要求额外审批或 SSO；工具不会替你扩大令牌权限。

“账号已连接”只确认身份；“检查目标写入权限”会创建一个不关联提交的空 Git 对象，不改变文件或触发部署。

本机草稿与隐私

点击「保存本机草稿」才会将照片和文案存入设备浏览器。草稿不包含令牌；只生成配置也不会上传照片。点击发布并确认后才会上传至公开 GitHub 仓库。

iPhone 可在 Safari 中添加到主屏幕。上传时请将页面保持在前台；不支持后台上传。Safari 私密浏览或系统清理可能使草稿丢失，请保留原图。
