GitHub 连接

优先使用本机 GitHub CLI、Git 登录或环境变量。没有现成登录时，可以填写仓库访问令牌。

令牌需要允许访问目标仓库，并具有 Contents 读写权限。不会保存到照片、配置文件或浏览器存储中。
